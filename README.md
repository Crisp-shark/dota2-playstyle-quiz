# 战局人格 · Dota 2 装备快选

**在线体验：** https://Crisp-shark.github.io/dota2-playstyle-quiz/

看 10 个短战况，每次从四张装备图里点一件最想拥有的装备。选择会映射到 5 个打法倾向，得到简短战局称号与 3 位同频英雄。全部 127 位英雄参与匹配，也可在结果页图鉴中查看，并逐一触发技能主题出场动画。

这是独立静态网页，没有账户、后端或 ChatGPT 依赖。答题进度仅保存在浏览器本机。GitHub Pages 从 `main` 分支根目录发布。

装备选择是假想情境，不考虑实际价格、英雄限制或版本最优出装；结果是玩家创作的趣味联想，不是心理测评、胜率预测或上分建议。装备图标来自 [Valve Dota 2 的公开资源](https://www.dota2.com/datafeed/itemlist?language=schinese)，英雄画像与装备相关权利属于 Valve；本站不是 Valve 官方产品。

本地检查：`node --test tests/*.test.cjs`。
