# 战局人格 · Dota 2 玩家风格测试

15 道四选一对局情境题，生成简短的 Dota 2 风格称号、同频英雄和完整英雄图鉴。全部 127 位英雄都可点击观看各自的技能主题出场动画；答题选项也有物品主题互动效果。

**在线体验：** https://Crisp-shark.github.io/dota2-playstyle-quiz/

这是独立静态网页，没有账户、后端或 ChatGPT 依赖。答题进度仅保存在浏览器本机。双击 `index.html` 可直接打开，或将本仓库作为 GitHub Pages 的 `main` 分支根目录发布。

英雄匹配属于玩家创作的娱乐内容，并非心理测评、胜率预测或上分建议。英雄名称、画像与相关权利属于 Valve；本站不是 Valve 官方产品。
